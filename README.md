# RNGArea
### Random on/off SW_A using *[Numerical Recipes LCG](https://s3.amazonaws.com/nrbook.com/book_C210_pdf/chap07c.pdf#page=11)*
|Var|Desc|
|------|--------------|
|Obj_arg0|Value controls chanceㅤ(I.E. 50 would be 50% chance, 30 for 30%)|
|Obj_arg1|Disabled: Roll onceㅤㅤEnabled: Roll continuously when in area|
|SW_A|On or off randomlyㅤㅤChance determined by Obj_arg0|
